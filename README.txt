BIRTHDAY WEB — READY TO CUSTOMIZE

1. Buka index.html di browser.
2. Kode rahasia default: 1431.
3. Untuk mengganti kode, buka script.js:
   const SECRET_CODE = "1431";

4. Masukkan foto ke folder assets dengan nama:
   photo1.jpg
   photo2.jpg
   photo3.jpg

5. Jika ingin musik, masukkan:
   song1.mp3
   song2.mp3
   song3.mp3

6. Ubah nama, surat, caption, lagu, dan ucapan langsung di index.html.

Catatan:
- Web ini tidak membutuhkan framework.
- Bisa dibuka secara offline setelah file Google Fonts tidak lagi diperlukan.
- Untuk tampilan paling mirip video, gunakan foto portrait dan layar HP.
